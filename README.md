# ⚽ Football Match Stat-Card Creator

A web application built to generate, manage, and visualize match stat cards for football players. 

## 📖 Overview
This project provides a clean user interface to manage player statistics and generate custom match-day stat cards. It includes full CRUD (Create, Read, Update, Delete) functionality for handling player data and match records seamlessly.

## 🛠️ Tech Stack
* **Frontend/Framework:** Blazor
* **Language:** C#
* **Database:** SQL Server

## ✨ Features
* **Player Data Management:** Easily add, edit, or remove player profiles and match stats.
* **Stat-Card Generation:** Dynamically render visual stat cards based on the stored database records.
* **Responsive UI:** Built with Blazor to ensure a smooth, interactive user experience.
